## 3. 口径补充（重写时确认的边界）

- **列表卡的主信息占比**不套数值卡阈值：列表卡以“列表头主层 ≥28px”代替 `maxFont / cardHeight` 断言；
  2×2/3×2 等列表尺寸的 hero 数字（如 countdown 48）与行标题共同构成层级。
- **3×2 信息增量**用信息项数（可见文本项）比较，而不是纵向覆盖率百分比：单值 1×1 天然占卡高比例更高，
  跨尺寸比较覆盖率会误杀已经铺满的 3×2。
- **单值卡（1×1/2×1）不套 22% 空带规则**：数字上下居中留白是正常构图。
- **D-04 行预算修正**：todo `3×2` 6→5 行、`3×3` 10→8 行（44px 行高 + 40px composer 的算术约束，见 DECISIONS D-04）；
  行数公式 `min(cap, floor((可用高度 + 4) / 48))`。
- **Display XL（D-07）**：只用于数字主信息（48/80/96/112），文本/标签仍只用 Fluent 字阶。
