# 项目定位

> 这里只写我要什么，不写怎么做。

这是一个给 Windows 平板用的个人桌面。启动器本身没什么功能，所有能力都来自插件。它只负责把插件放上全屏桌面，再带一个内置 Agent。

没有应用图标，没有应用抽屉，没有搜索。形态像 iOS 桌面，但上面放的是小组件。开机看到的直接就是一整屏小组件。

为什么自己做：开始菜单和桌面对手指不够直接，市面上的方案要么太复杂，要么不合我的习惯。所以自己写一个，够用就行，不追求大而全。

只给我自己用，所以一切按我的习惯来，不考虑通用场景。**这是个人玩具，不讲工程质量，能跑、顺手、好玩就行，先有东西再说。**

# 桌面

- 全屏，占据整个屏幕，作为平板上的主入口。
- 不接管资源管理器、文件管理、任务栏、系统托盘，只是盖在最上面的一层桌面。
- 一页或多页，左右滑动切换，像 iOS 桌面。
- 每页是一个网格，小组件按尺寸摆进去：小方块、横条、大方块，具体尺寸由插件自己定。
- 点击小组件触发它的默认操作：点时钟可能没反应，点番茄钟开始/暂停计时，点 TODO 里的一项打勾。
- 长按进入编辑模式，可以拖拽移动、改大小、删除。
- 没有"启动应用"这个动作，所有东西都通过小组件直接操作。

# 插件

- 插件是桌面的全部功能来源。装上就多一块，卸掉就少一块，启用/禁用随时切，不影响别的插件，也不用改启动器。
- 插件要说明自己是谁、提供哪些小组件、每个小组件默认多大、让不让 Agent 读或写自己的状态。
- 一个插件可以有多个小组件（比如 TODO 的列表型和紧凑型）；也可以一个小组件都没有，只在后台跑，比如久坐提醒。
- 插件之间不直接通信。要协作就让启动器在中间转达，免得互相勾连，也方便单独关掉。
- 插件自己管自己的配置和状态。
- 插件想干什么就干什么：不做隔离、不做权限、不做安全设计。这是我自己用的东西，出事我认。

# 内置 Agent

- 内置在启动器里，不是接进来的第三方服务，跟启动器一起交付。
- 不是通用 AI，是桌面的智能入口：听懂人话，决定该叫哪个插件干活。
- 能联网，也能读插件声明以外的数据。能访问什么由插件自己说了算，不需要我逐条授权。
- 例子：我说"我要开始专注"，它去开番茄钟；说"我接下来有什么安排"，它读 TODO 汇总；说"今天天气怎么样"，它读天气插件然后回我一句话。

# 插件清单

## 时钟

显示当前时间和日期。支持 12/24 小时制切换。可以有多种尺寸，比如只显示时间的紧凑型、显示日期和星期的大卡片。

## 天气

显示当前城市的天气和温度，定时联网更新。城市和更新频率可以配置。卡片放桌面上，Agent 也能读到当前状态。

## 番茄钟

桌面上的计时器。可以开始、暂停、跳过，计时结束弹通知。Agent 也能帮我开一个指定时长的番茄钟。

## 久坐提醒

隐藏插件，平时在后台跑。记录我连续坐了多久，超过设定的阈值就提醒我起来动一动。状态对 Agent 开放，问它我今天坐了多久能答上来。想要的话，桌面上也可以放个极简的状态小点。

## TODO

桌面上的待办列表。直接在小组件上勾选完成或加新任务。Agent 能读列表，也能帮我加任务、完成任务。

## 倒数日

在桌面上显示重要日子的倒数：生日、纪念日、考试、项目截止。可设每年重复，支持单事件和列表两种小组件。

# Agent 与语音

- Agent 不是插件，是桌面右下角一个常驻的浮空入口：小按钮 → 半高输入窗 → 全高浮栏，同一块浮层长大、原路收回。
- 语音是主入口：点按钮或按住空格**立即开始说话**，松开就发；打字只是补充。没有唤醒词、没有常驻监听、没有人脸/摄像头。
- 语音直接交给云端 MiMo 理解（音频只在当前这一轮发一次），再转成文字留档；之后的对话只用文字，不重发音频。
- 回应用语音读出来；我说的话用声纹标记，不靠文字标签解释界面。
- 全屏语音页、面板形态设置、底部 dock 都不需要；设置集中在设置页，长按桌面空白进编辑工具栏、或 Ctrl+, 可达。

# 怎么操作

- 触控、鼠标、键盘、触控板都要支持，触控是主要场景。
- 左右滑动切页；点击触发小组件默认操作；长按进编辑模式，可以拖拽改位置、改大小。捏合手势可以考虑用来进出编辑模式，暂时不做。
- 鼠标照常：悬停提示、右键菜单、滚轮翻页或滚列表型小组件里的内容。
- 键盘作为辅助：方向键在小组件之间挪焦点，Enter 触发，Esc 退出编辑；另外支持自定义全局快捷键，临时藏起/显示整个桌面层。
- 触控板跟鼠标类似，另外支持双指左右滑翻页；设备支持精确触控板的话，可以加三指滑动显示/隐藏桌面层。

# 明确不做的事

- 不替代 Windows 资源管理器，不接管文件管理、窗口管理、任务栏、系统托盘。它只是全屏的小组件层。
- 不提供"启动应用"功能：桌面上没有应用图标，也没有搜索框，所有交互都通过小组件完成。
- 不在本地跑大模型。语音对话依赖云端，本地只负责录音、放音、转发和界面。
- 不做唤醒词、不做常驻麦克风监听、不做人脸/摄像头识别（v0.3.0 已移除）。
- 不追求通用性：布局、交互、默认插件都围绕我自己的习惯，不刻意兼容所有平板和所有人。
- 不做多用户，不做企业级产品，配置和权限都按"单用户本地使用"来。
