# 项目定位

这是一个为 Windows 平板电脑设计的个人桌面环境。它本身不承担复杂功能，所有具体能力都由插件提供。启动器只负责把插件加载进来，给它们一个全屏的展示空间，以及一个内置的 Agent。

这个桌面环境没有应用程序图标，也没有传统意义上的应用抽屉或搜索。它的形态更接近 iOS 桌面，但上面放的不是 App 图标，而是各种小组件。用户开机后看到的直接是一个布满小组件的全屏桌面。

做这个桌面的原因很简单：手头的 Windows 平板在日常使用中，开始菜单和桌面对手指操作不够直接，而市面上现有的方案要么太复杂，要么不完全符合个人使用习惯。所以决定自己写一个，功能够用就行，不追求大而全。

目标用户 initially 只有开发者本人，因此很多设计会围绕个人习惯展开，不需要考虑通用场景。

# 核心体验

启动器运行后占据整个屏幕，作为平板上的主要入口。它不会关闭 Windows 资源管理器，也不会接管文件管理、任务栏或系统托盘。它只是一个全屏的、更适合触控和语音交互的桌面层。

整个界面由一页或多页小组件组成。用户可以左右滑动切换不同的页面，类似 iOS 桌面的多页布局。每一页都是一个网格，小组件按照预设尺寸摆放在网格中。小组件可以是小方块、横条或大方块，具体尺寸由插件声明。

点击一个小组件会触发它的默认交互。例如点击时钟可能没反应，点击番茄钟会开始或暂停计时，点击 TODO 列表中的某一项会标记完成。长按小组件可以进入编辑模式，此时可以拖拽移动位置、调整大小或删除。

不存在启动应用程序这个动作。所有功能都通过小组件直接呈现和操作。

# 插件系统

插件是桌面的全部功能来源。每个插件是一个独立的 C# 模块，启动器在运行时会动态加载它们。插件需要声明自己的基本元信息、提供哪些小组件、每个小组件的默认尺寸，以及是否允许 Agent 读取或写入自己的状态。

每个插件可以提供一种或多种小组件。例如天气插件可能只提供一个天气卡片，而 TODO 插件可能提供列表型和紧凑型的两种小组件。每个小组件独立声明自己的尺寸和刷新行为。

插件也可以不提供任何小组件，只在后台运行。这类插件被称为隐藏插件。它们不占据桌面空间，但可以被 Agent 读取状态或被其他事件触发。例如久坐提醒插件可能只在后台计时，并在需要时弹出通知。

插件之间不直接通信。如果它们需要协作，必须通过启动器核心进行消息转发。这样可以避免插件之间产生隐式依赖，也便于后续单独启用或禁用某个插件。

每个插件自己管理自己的配置和状态持久化。启动器只提供一个最小化的宿主环境，不介入插件内部逻辑。

# 内置 Agent

启动器内置一个 Agent，作为整个桌面的智能入口。它不是通用人工智能，而是专门用来协调插件、响应语音指令、调用在线服务的小模块。

Agent 可以理解用户的自然语言指令，并决定调用哪些插件来执行。例如用户说“我要开始专注”，Agent 会启动番茄钟插件。用户说“我接下来有什么安排”，Agent 会从 TODO 插件中读取待办事项并汇总。用户说“今天天气怎么样”，Agent 会读取天气插件并生成一句自然语言回复。

Agent 可以联网，也可以访问插件声明之外的数据。由于这是个人自用项目，并且会开源，不在本地做严格的权限隔离。Agent 和插件之间的访问关系由代码层面的接口约定，而不是由用户逐条授权。

Agent 不是外部接进来的第三方服务，它就是启动器本身的一部分，第一期就要交付。

# 第一期插件清单

## 时钟

在桌面上显示当前时间和日期的小组件。支持 12 小时制和 24 小时制切换。可以提供多种尺寸，例如只显示时间的紧凑型，和同时显示日期、星期的大型卡片。

## 天气

显示当前城市的天气状况和温度。需要定时从网络获取数据。用户可以配置城市和更新频率。天气信息以卡片形式显示在桌面，Agent 也可以读取当前状态。

## 番茄钟

在桌面上显示一个计时器小组件。用户可以手动开始、暂停、跳过。计时结束时弹出通知。Agent 可以帮用户开始一个指定时长的番茄钟。

## 久坐提醒

这是一个隐藏插件，主要在后台运行。它会记录用户连续使用电脑的时长，当超过设定阈值时通过通知提醒用户起身活动。它也向 Agent 开放状态读取，Agent 可以在用户询问时汇报今天已经坐了多久。如果用户希望，也可以提供一个极简的状态小点显示在桌面。

## TODO

在桌面上显示待办事项列表。用户可以直接在小组件上勾选完成或添加新任务。Agent 可以读取 TODO 列表，也可以帮用户添加或完成任务。

# 人脸唤醒与语音交互

人脸唤醒和 LLM 语音功能不是独立插件，而是 Agent 系统的一部分，和启动器一起交付。

系统在后台调用摄像头进行人脸识别。当检测到已注册的人脸时，自动唤醒 Agent 的语音交互模式。用户可以接着用语音向 Agent 发出指令，例如查询天气、开始番茄钟、添加 TODO 等。

语音对话通过云端大语言模型 API 实现，不运行在本地。本地只负责录音、唤醒、播放语音和转发请求。这个功能需要摄像头和麦克风权限，在 Windows 上直接由系统管理即可。

桌面上可以提供一个状态指示器，显示当前 Agent 是否在监听语音。

# 输入与交互

启动器需要同时支持触控、鼠标、键盘和触控板四种输入方式。触控是主要场景。

左右滑动用于切换小组件页面。点击用于触发小组件的默认交互。长按小组件进入编辑模式，此时可以拖拽移动位置或调整大小。捏合手势可以考虑用于进入或退出编辑模式，但不作为第一期的必需品。

鼠标操作保持常规体验。悬停显示提示，右键打开小组件菜单，滚轮用于左右翻页或滚动列表型小组件内部内容。

键盘操作作为辅助。支持方向键在小组件之间移动焦点，Enter 触发当前小组件，Esc 退出编辑模式。也支持自定义全局快捷键用于临时隐藏或显示整个桌面层。

触控板支持与鼠标类似，同时可以识别双指左右滑动翻页。如果设备支持精确触控板，可以考虑加入三指滑动手势用于显示或隐藏桌面层。

# 权限与隐私

这个项目是个人自用并开源的，不在本地做复杂的权限沙箱或隐私保护设计。插件需要网络、摄像头、麦克风、文件读写等权限时，直接依赖 Windows 系统层面的权限管理即可。用户如果fork或自行使用，需要自己判断安全风险。

# 明确不做的事

这个项目不会替代 Windows 资源管理器，也不会接管文件管理、窗口管理、任务栏或系统托盘。它只是一个全屏的桌面小组件层。

项目不会提供应用启动功能。桌面上不显示任何应用程序图标，也不提供搜索框来查找应用。所有交互都通过小组件完成。

项目不会本地运行大语言模型。LLM 语音功能依赖外部 API，本地只负责录音、唤醒、播放语音和转发请求。

项目不追求通用性。界面布局、交互方式和默认插件选择都会围绕开发者本人的使用习惯设计，不会刻意兼容所有 Windows 平板或所有用户场景。

项目不打算做成多用户系统或企业级产品。配置和权限管理都以单用户本地使用为前提。
