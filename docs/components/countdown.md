# 倒数日（countdown）

桌面上的重要日子倒计时：生日、纪念日、考试、项目截止。

## 数据模型

```ts
interface Countdown {
  id: string;
  title: string;
  targetDate: string;   // YYYY-MM-DD
  repeatYearly: boolean; // 默认 false；true 时按月-日每年重复
  color: string;        // Fluent token 名，默认 accent
  createdAt: string;    // ISO
}
```

存储：`countdown.items`，不设上限。

## 尺寸与布局

| 尺寸 | 内容 |
|---|---|
| `1×1` | 一条最接近的事件：天数 + 标题（截断） |
| `2×1` | 一条事件：标题 + 天数 |
| `2×2` | 列表（最多 4 条），按日期升序 |
| `3×2` | 列表 + `+` 新增按钮 |

## 显示规则

- 未来：`还有 N 天`
- 今天：`就是今天`（高亮）
- 过去：`已过 N 天`（默认显示，可在设置里关掉）
- 每年重复的事件：自动换算到下一个周年日；已在今年的显示今年。

## 自适应

- `1×1` 只留最近一条的天数 + 截断标题；列表从 `2×2` 起。
- 天数数字用 `clamp()` 缩放，标题超宽省略。

## 交互

- 点 `+` = 弹出表单：标题、日期、是否每年重复、颜色。
- 点击某条 = 编辑。
- 长按某条 = 删除。

## 配置项

- 是否显示已过去的事件（默认显示）
- 排序：按日期升序（唯一排序，不提供手动排序）
- 是否显示未到 7 天事件的强调色（默认开）

## Agent 工具

| 工具 | 参数 | 返回 |
|---|---|---|
| `countdown.list` | `{ includePast? }` | 事件数组（含剩余天数） |
| `countdown.add` | `{ title, targetDate, repeatYearly?, color? }` | 新事件 |
| `countdown.remove` | `{ id }` | 删除结果 |

## 边界与异常

- 无事件：空状态文案“还没有倒数日”。
- 日期非法或早于今天且不重复：允许，显示“已过 N 天”。
- 一年内多条同一天：并列显示。
- 数量达 50：`add` 返回错误。

## 依赖的宿主能力

`init(theme)`、`getConfig/setConfig`、`notify(text)`。

## 不做什么

农历、当天推送提醒（先不做，靠桌面卡片自己看）、图片背景、分享。
