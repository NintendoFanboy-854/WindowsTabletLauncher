# 时钟（clock）

## 什么时候用

抬手看时间/日期。桌面最常被看到的东西，不需要任何操作。

## 默认交互

- 点击卡片 = 切换 12 / 24 小时制（即时生效，存到配置里）。

## 编辑模式里能改什么

- 改尺寸、打开设置面板。

## 尺寸档位与显示内容

| 档位 | 显示 |
|---|---|
| `1×1` | 只有时间 `19:41`，字号自适应，放不下日期 |
| `2×1` | 时间（大）+ 日期（小） |
| `3×2` | 超大时间 + 日期 + 星期 |

## 自适应

- 字号用 iframe 视口单位 `clamp()` 随卡片缩放。
- `1×1` 只显示 `HH:MM`，不显示秒和日期（秒从 `2×1` 起保留）。
- 字体基准用 Fluent 字体 token，触控目标不小于 40×40。

## 配置项

- 12 / 24 小时制，默认 24。
- 显示秒，默认开（插电用，不在乎耗电）。
- 日期格式：`10月18日 星期日` / `2026-10-18` / `10/18 Sun`，默认第一种。
- 时区：第一期跟系统走，不做配置。

## 存什么数据

只存配置（小时制、显示秒、日期格式），没有历史数据。

## Agent 能做什么

- 只读：注册 `clock.now`，回答“现在几点 / 今天几号”。
- 不能改任何配置。

## 不做什么

闹钟、倒计时、秒表、世界时钟、日程、农历。

## 待定问题

无。
