## 约定

- 只有要写进 README / 发布说明的**精选图**才放这里，按 `docs/images/<版本>/` 归档并在 README 引用。
- 验收/审计的原始截图属于证据，放 `shots/releases/<版本>/`、`shots/milestones/`、`shots/audits/`（见
  [../audits/README.md](../audits/README.md)），不要提交进本目录。
- **v0.4.5 / v0.5.0 / v0.6.0 未系统截图**；这三个版本之后的界面（壁纸三模式、说明条参与布局、欣赏壁纸）
  以源码与 `docs/` 规范为准，后续补图时新增 `v045/`、`v050/`、`v060/` 等目录。
- 当前未被 README 直接引用的旧图（v030 14 张、v037 1 张）是**旧版本视觉存档**，不要当作未使用文件清理。
