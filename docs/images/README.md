## 约定

- 只有要写进 README / 发布说明的**精选图**才放这里，按 `docs/images/<版本>/` 归档并在 README 引用。
- 验收/审计的原始截图属于证据，放 `shots/releases/<版本>/`、`shots/milestones/`、`shots/audits/`（见
  [../audits/README.md](../audits/README.md)），不要提交进本目录。
- **v0.6.0 截图已补齐（`v060/`）**：壁纸三模式 / 欣赏壁纸 / 说明条参与布局 / 说明文字 v3 / 卡片与说明条按压态；
  证据源为本地 `shots/acceptance-v060/`，新增版本时先更新本表与根 README 的引用。
- 未被 README 直接引用的旧图（v030 16 张、v037 6 张、v040 2 张、v050 1 张）是**旧版本视觉存档**，不要当作
  未使用文件清理；新增图库版本时先更新本表与根 README 的引用。
