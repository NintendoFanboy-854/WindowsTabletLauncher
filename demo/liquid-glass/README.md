## 物理模型

### 1. 全局速度场

液滴不是被正弦路径牵着走，而是被一个全局、无散度的速度场驱动：

```
ψ(x,y,t) = W(x,y) · [ A₁ sin(k₁x+ω₁t) cos(k₁y)
                    + A₂ cos(k₂x) sin(k₂y+ω₂t)
                    + A₃ sin(k₃(x+y)+ω₃t) cos(k₃(x−y)) ]
u = (∂ψ/∂y, −∂ψ/∂x)
```

- `div u ≡ 0`，面积/体积守恒；
- `W(x,y)` 是边缘归零的窗口，液滴不会漂出屏幕；
- 每颗液滴的“内部瓣”（lobe）被当地流速平流；
- 接触线钉扎：流速低于阈值时不动，高于阈值才滑移。

### 2. 合并与分裂

每颗珠有一个**物理体积**。一个珠可以由一个或多个瓣组成：

- 两个珠的接触圆相交 → 合并：体积相加，质心按体积加权，新珠是一颗更大的单冠；
- 流场把同一个珠内部的瓣拉开 → 分裂：按主轴做二分组，体积守恒，得到两颗更小的珠；
- 分裂前要求两颗新珠的接触圆已经分开，避免立刻又合并。

合并/分裂的最终状态是**体积正确的 Young-Laplace 轮廓**。过渡用 0.75s 的时间拉伸动画，真实毛细合并是毫秒级；这里只是把时间轴拉长，形状终点是物理的。

### 3. 重力轮廓

球冠只在 `Bo = ρgR²/γ ≪ 1` 时成立。默认 1.5mm 水珠 `Bo ≈ 0.2`，接近球冠；把“尺寸”调大，轮廓会自动摊成水洼。

轮廓由轴对称 Young-Laplace 方程解出：

```
dr/ds = cosφ
dz/ds = sinφ
dφ/ds = (Δp₀ + ρgz)/γ − sinφ/r
```

无量纲化长度用毛细长度 `l_c = sqrt(γ/ρg) ≈ 2.727mm`；RK4 积分到 `φ=θ`，得到 `R/H/V`，再重采样成 64 点的 `h(q)` LUT。场着色器按 `q=r/R` 和 `Bo` 采样。

### 4. 光学

- **透镜成像**：视线在表面折射后打到壁纸，采样 `Q = P + d1·h/(−d1.z)`；接触线 `h→0`，位移自然归零。
- **精确 Fresnel**：s/p 平均，`F0=0.02`，不再用 Schlick。
- **三波长 Snell**：`nR=1.331, nG=1.333, nB=1.344`，各自 `refract`。
- **HDR 环境**：`studio_small_03` 的 256×128 RGBE，生成 128×128 cubemap；反射用 `texture(uEnv, R)`，光源方向取环境最亮方向。
- **屏幕玻璃**：water→glass→pixel 的两次折射，厚度可调。
- **底色介质**：不是简单 `mix`，而是参与介质：

```
L = h / (−T.z)
T = exp(−σ_t · L)
trans = T · background + (1 − T) · albedo
```

暗色主题是吸收，亮色主题是散射；和 Fluent 的明暗语义一致。

### 5. 线性色彩

壁纸用 `SRGB8_ALPHA8` 解码到 linear；环境、底色也在 linear 里算；最后用 256 项 sRGB LUT 编码回显示空间。物理计算不再发生在 sRGB 数值上。

## 三趟管线

```
① 几何（0.24 屏宽）  → SDF + 重力轮廓高度
② 法线（同一分辨率）  → 高度场中心差分
③ 合成（全分辨率）    → 三波长透镜 / Fresnel / HDR 环境 / 介质 / 高光 → 屏幕
```

没有 ping-pong、没有离屏合成和 blit。反射来自 HDR cubemap，不需要上一帧。

## 参数

| 参数 | 作用 |
|---|---|
| 液滴数量 | 初始瓣数；合并/分裂后实际珠数会变 |
| 尺寸 | 物理接触半径（mm）；调大后按重力摊成水洼 |
| 接触角 | 球冠在接触线的角度；80° 是疏水屏 |
| 流场 | 全局速度场强度 |
| 钉扎 | 接触线静摩擦阈值 |
| 颈宽 | 合并/分裂过渡的**视觉**颈宽，不是物理量 |
| 模糊 | 0 = 清透，往上加磨砂 |
| 高光 | 曲面高光强度 |
| 底色 | 介质光学厚度 |
| 环境亮度 | HDR 反射强度 |
| 环境旋转 | 旋转 HDR 环境 |
| 玻璃厚度 | 屏幕玻璃层厚度（mm） |
| 速度 | 整体时间倍率 |

## 自适应

`EXT_disjoint_timer_query_webgl2` 读真实 GPU 耗时，预算按 120fps（8.3ms）定，钉在 60fps 输出。五档只调输出倍率，几何层固定 0.24 屏宽，换档不重建。

## 仍然是近似的地方

- 合并/分裂过渡是**时间拉伸**的准静态动画，不是实时 Navier-Stokes；
- 分裂判据是几何阈值，不是真正的 Rayleigh–Plateau 不稳定性；
- 流场是给定的外部场，不是从空气压力/屏幕倾斜解出来的；
- 环境是一张固定 HDR 图，不是实时房间；
- 接触线亚像素弯月面没有建模；
- 液滴在流场中的形变没有解，只做质心平流 + 拓扑分裂（低 Capillary 数下形变小）。

这些都在 README 里明说，不假装是完整流体仿真。
