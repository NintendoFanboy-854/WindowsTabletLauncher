# Liquid Glass · 水珠演示

一颗（或几颗）坐在壁纸上的水珠：球冠高度场 + 真实的 Snell 折射，不是“平面玻璃板 + 一圈倒角”。

## 打开

双击 `index.html`（不需要服务器、不需要构建、无依赖）。

| 地址 | 用途 |
|---|---|
| `index.html` | 风景底图 |
| `index.html#chart` | 网格测试图，边缘压缩和“包边”看得最清楚 |
| `index.html#chart&contact=85&fill=0.45` | hash 可以覆盖任意参数，方便 A/B |

## 几何

单滴是球冠。接触角 θ、接触半径 R、冠高：

```
H = R · tan(θ/2)
```

高度按归一化半径 `q = r/R` 走球冠剖面：

```
h(q) = H · (sqrt(1 - q²sin²θ) - cosθ) / (1 - cosθ)
```

`q=0` 顶点，`q=1` 接触线，`h=0`。斜率在接触线正好是 `tanθ`，所以边缘是“立起来”的，不是一圈倒角。

法线不靠距离场猜，而是对高度场做中心差分：

```
N = normalize(vec3(-∂h/∂x, -∂h/∂y, 1))
```

### 融合

距离场用 `smin` 平滑并集；高度不是距离场的线性映射，而是先把距离场变成“到接触线的归一化距离” `u`，再走球冠剖面。于是：

- 接触线、遮罩、高度场三者严格一致；
- 两滴靠近时，`smin` 的 fillet 自动把接触线往外鼓，形成液体颈；
- 液丝（间距 2.0R–2.7R）也进入高度场，是低矮的液体桥，不是一张平的膜。

## 光学

### 透镜成像

视线竖直向下，在表面折射，打到 z=0 的壁纸：

```
d1 = refract((0,0,-1), N, 1/n)
Q  = P + d1 · h / (-d1.z)
```

采样 `Q` 处的壁纸，而不是按法线平移一点。关键性质：

| 位置 | 行为 |
|---|---|
| 中心 | `h` 最大，但法线竖直，位移为 0 |
| 中段 | 壁纸被放大（球冠是凸透镜） |
| 边缘 | `h→0`，位移归零；但 `dQ/dr` 很大，衬底被压缩进一条窄环 |
| 接触线 | 水→空气的入射角接近临界角，Fresnel 反射率升到 ~0.35–0.40 |

边缘那圈“包边”就是**压缩环 + 掠射角 Fresnel + 接触线暗线**，不需要额外的倒角，也不需要 TIR（80° 时还没到全反射）。

### 材质常数

| 项 | 值 | 说明 |
|---|---|---|
| 折射率 | 1.333 | 水；面板可调 1.30–1.40 |
| 色散 | 1% | n 从 1.331 到 1.344，真实水的相对差 |
| F0 | 0.02 | 水→空气，不是玻璃的 0.04 |
| 吸收 | 接近 0 | 毫米级水珠在可见光下几乎不吸收 |
| 高光 | 指数 256 | 曲面把光聚成一个小点，不是一圈弧 |

### 环境反射

只取壁纸的低频颜色：上下半球平均色 + 5 级 mip 的局部色。反射里没有平移后的清晰壁纸，所以不会出现“第二层”。面板的“环境反射”控制局部色混入比例。

## 为什么不解 NS

毫米级水滴的毛细松弛时间：

```
τ = μR/γ ≈ 1.4×10⁻⁵ s
```

固有频率约 43Hz，而动画 47 秒一圈，慢三个数量级。所以每一帧液滴都处于**准静态平衡**：

- 形状：Young-Laplace 的球冠解析解；
- 质心：二阶阻尼振子，带一点过冲；
- 合并：`smin` 的准静态颈，不模拟颈的生长时间（真实生长只有毫秒）。

这不是“偷懒的流体”，而是尺度上正确的简化：在这个时间尺度下，液滴本来就应该瞬间回到平衡形状。

## 三趟管线

```
① 几何（fixed 0.18 屏宽）  → 距离场 + 球冠高度
② 法线（同一分辨率）        → 高度场中心差分
③ 合成（全分辨率）          → 透镜 / 菲涅尔 / 环境 / 高光 → 屏幕
```

没有流场输运、没有 ping-pong、没有离屏合成和 blit。反射是低频环境色，不需要上一帧；合成直接画到画布。

低分辨率只输出几何，颜色全程全分辨率算，所以放大倍数再大也不会有马赛克。

## 参数

面板默认收起（按 **H** 展开）。性能相关的项全是自动的。

| 参数 | 作用 |
|---|---|
| 液滴数量 | 同时存在几滴 |
| 融合 | `smin` 的宽度；0 = 硬边相交，越大脖子越粗 |
| 接触角 | 球冠在接触线的角度；80° 是珠子，60° 更摊，85° 更立 |
| 折射率 | 水 1.333；越大透镜越强 |
| 色散 | 红蓝折射率差；水的实际相对差约 1% |
| 模糊 | 0 = 清透，往上加磨砂 |
| 尺寸 | 每一滴的半径 |
| 高光 | 曲面高光强度 |
| 底色 | 中性面颜色混入液滴本体的比例；0 = 全透 |
| 环境反射 | 低频环境色混入反射的比例 |
| 投影 | 接触阴影 |
| 速度 | 整体漂移速度 |

## 自适应

用 `EXT_disjoint_timer_query_webgl2` 读真实 GPU 耗时，预算按 120fps（8.3ms）定，留一倍余量，然后钉在 60fps 输出。五档只调输出倍率，几何层固定 0.18 屏宽 —— 换档时形状不会跳。

HUD 里 `质量 3/5` 是当前档，`GPU x.x ms` 是实测耗时。

## 无缝循环

所有运动频率都是整数（3 / 4 / 5 / 6），相位走满 `2π` 回到起点，周期约 47 秒，循环点无跳变。

## 与产品的关系

产品里的 `src/host/desktop/liquidGlass/` 用的是同一套球冠高度场 + 透镜成像；demo 只是多了参数面板、HUD、对比原图和背景生成。产品不包含任何调试 UI。
