# Liquid Glass · 相场水珠演示

这是产品移植前的独立 demo。和上一版相比，重点不是再调参数，而是把两个结构性错误拆掉：

- **不再按“种子包围盒”开 scissor**。上一版的矩形缺口来自 JS 种子和相场各自演化，液滴拉长/合并后种子框对不上。现在玻璃层整屏绘制，只靠 alpha 回到页面原生壁纸，没有矩形裁剪。
- **不再用“到接触线的距离”查 1D 高度轮廓**。距离场在中轴处有折痕，法线不连续，就会看到一条脊线。现在高度由 Poisson 容量场 + 球冠剖面重建，法线用 ∇ψ 的解析链式法则，几何上不会再有中轴折痕。

## 相场：不再手工摆水滴

初始液体不是固定数量的圆滴。重置时随机撒一些平滑的液体核（元球），再用**总液体量**做全局阈值；核之间可以重叠，形成有机的初始形状。之后完全交给相场：

```
∂tφ + ∇·(uφ) = ∇·( M [ ∇φ − (4/ε) φ(1−φ) n ] )
n = ∇φ / |∇φ|
```

- 平流项和界面通量都写成**面通量**，整场求和会望远镜式抵消；
- 界面通量把被数值扩散抹开的 tanh 重新收窄；
- 没有 λ 加法、没有“目标平均 φ”，不会在空气里加出一层雾；
- 合并、颈缩、断裂都由界面自然发生。

相场是 0.22 屏高，ε 默认 3 格，迁移率 0.5 格²/秒，2 个 substep/帧。这个组合比上一版“ε=2.2、M=4”更稳：不会在颈部出现棋盘格，也不会把液滴锁成网格台阶。

### 总质量

通量形式本身守恒，但最后为了把 φ 限制在 [0,1] 会 clamp，长时间会有一点点漂移。demo 在 1/4 分辨率的探针上回读 φ 平均值，每 ~0.22 秒做一次**乘法校正**：

```
φ ← clamp(φ · (M_target / M_current), 0, 1)
```

所以 HUD 里的“质量漂移”会稳定在 ±0.3% 以内。下拉“质量校正”按钮可以看原始漂移。

- 总质量：由通量形式 + 探针校正保持；
- 每只液滴的质量：在没有合并/分裂时，液滴之间隔着空气，界面通量为零，因此各自守恒；合并/分裂时质量按场自然分配；
- 距离场/种子不再参与质量或高度。

## 高度：Poisson 容量场 + 球冠

2D 相场只给接触线覆盖。渲染需要 3D 高度，但**不能**用“到接触线的距离”去查轮廓——那正是脊线的来源。

改为解一个 Poisson 方程：

```
∇²ψ = −1   在 φ ≥ 0.5 内
ψ = 0      在接触线上
```

ψ 是光滑的“容量场”，圆滴中心 `ψ = R²/4`。对每只液滴（CPU 在 1/4 分辨率探针上做连通域标记）取面积等效半径 R，然后：

```
q = 4ψ / (R·PHI_H)²
h/H = (sqrt(cos²θ + sin²θ·q) − cosθ) / (1 − cosθ)
H = R·tan(θ/2)·volumeScale
```

- q=0 在接触线，q=1 在顶点；
- 这个剖面在 q=0 处斜率正好是 tanθ，在 q=1 处高度正好是 H；
- 非圆形/合并后的形状 q 到不了 1，顶点自然更低，颈部更薄；
- **法线**用 `∇h = H·(dshape/dq)·(4∇ψ/R²)` 解析计算，不再对 h 做跨干/湿格的中心差分，所以接触线附近也没有网格锯齿或脊线。

每只液滴的 R 由探针连通域给出，并扩散到全屏供高度着色器双线性采样。液滴合并/分裂时 R 只影响整体高度尺度，不会在接触线处产生台阶。

### 体积

每只液滴的球冠体积约为 `k·R³`。所有液滴的体积和与初始值比较，得到一个全局 `volumeScale`，慢速平滑。这样合并/分裂时 3D 体积不会突然翻倍或丢失；它不改变相场的质量守恒。

## 外部流场

流场是解析无散场（streamfunction 求旋度），只用低波数、慢时间模态：

```
ψ_flow = win(x,y) · [0.70 m1 + 0.45 m2 + 0.25 m3]
u = (∂ψ/∂y, −∂ψ/∂x)
```

- 在屏幕边缘之前衰减到 0，避免把液滴推到画面外再被边界裁掉；
- 默认强度 0.02，运动很慢；想看得更明显可以拉到 0.06–0.1；
- 流场是给定的外部场，不是从空气压力/屏幕倾斜解出来的。

## 渲染

页面底部是原生 `<img id="pagebg">`，壁纸保持浏览器原生清晰度。WebGL 画布只画玻璃：

```
① 保守相场 2 substep/帧                  → φ
② 红黑 SOR 解 Poisson 容量场              → ψ
③ 几何：球冠高度 + 解析法线 + alpha      → 玻璃层（φ 分辨率）
④ 合成：整屏 quad，mask 外的像素提前返回  → 透镜 / 菲涅尔 / HDRI / 介质
```

- 不再全屏重画壁纸；背景只在液滴内部被采样；
- 没有 scissor，所以不会有矩形边界；
- 输出分辨率自适应 0.55–1.4 CSS DPR；
- 相场/高度固定 0.22 屏高，和输出 DPR 解耦。

### 光学

- 三波长 Snell 折射，屏幕玻璃两次折射；
- 精确 s/p Fresnel；
- HDR 环境 cubemap（`spruit_sunrise`），方向光取环境最亮方向；
- 参与介质：`trans = exp(−τ)·bg + (1−exp(−τ))·albedo`；
- sRGB 解码/编码 LUT；
- 接触线附近用更高的背景 mip 做面积预滤波，避免高对比壁纸被压成矩形锯齿。

## 仍然是近似

- 相场是 **2D 接触线覆盖**，不是 3D 相场；高度是 Poisson/球冠重建的，不是被相场直接演化的；
- 相场用一阶迎风平流，界面宽度有限；为了稳定，ε 默认 3 格，边缘比真实水珠软；
- 总质量靠探针乘法校正保持，是数值校正，不是严格的 Lagrange multiplier；
- 体积是全局重标定，不是每只液滴独立守恒；
- 流场是给定外场，不是 NS 求解；
- 环境是固定 HDR 图，不是实时房间；
- 没有建模亚像素弯月面；
- 测试图里的矩形/网格是折射后的背景，不是裁剪。真实观感请用照片或自己的壁纸。
