## 相场接触线：Conservative Allen-Cahn

不再有 lobe / component / 0.75s 插值。接触线由一个连续的相场 φ 表示：

```
∂tφ + u·∇φ = M(ε²∇²φ − W'(φ)) + λ
W(φ) = φ²(1−φ)²
λ = k(φ_target − ⟨φ⟩)
```

- φ≈1 液体，φ≈0 空气，界面是 tanh，宽度 `ε` 可调；
- `u` 是全局无散度流场，直接平流 φ；
- λ 用 1×1 mip 的平均 φ 做体积约束；
- 合并、拉长、颈缩、断裂都由界面自然发生，没有拓扑事件。

实现是 2–3 个 CAC substep/帧，相场固定 0.24 屏宽，显式稳定（`ε` 几个格）。

## 高度重建

2D 相场只解决接触线拓扑，不直接给 3D 球冠。高度用**跳洪距离场**重建：

```
d = sign(φ−0.5) · distance to φ=0.5
rq = 1 − clamp(d / Rref, 0, 1)
h = H0 · profile(rq)
```

`profile` 是 1D 轴对称 Young-Laplace（带重力）解出来的 `h/H`；`Rref/H0` 由“尺寸/接触角”对应的基础滴决定。法线由 h 的中心差分得到，透镜/菲涅尔/HDRI 都在合成层。

相场 → 跳洪 seed（8 个方向、步长 256…1）→ 最近界面距离 → 高度。全程 GPU，无 CPU 回读。

## 光学

- **透镜成像**：三波长 Snell，`Q = P + d1·h/(−d1.z)`；接触线 h→0，位移归零。
- **精确 Fresnel**：s/p 平均，`F0=0.02`。
- **HDR 环境**：`spruit_sunrise` 的 128×128 cubemap；固定方向光取环境最亮方向。
- **屏幕玻璃**：water→glass→pixel 的两次折射。
- **底色介质**：`trans = exp(−σL)·bg + (1−exp(−σL))·albedo`；暗吸收、亮散射。
- **线性色彩**：壁纸 `SRGB8_ALPHA8` 解码，物理计算 linear，最后 sRGB LUT 编码。

## 透明玻璃层 / scissor

页面底部是原生 `<img id="pagebg">`，壁纸保持原生清晰；WebGL 画布只负责玻璃，输出 `alpha = mask`。合成时按初始流场种子的包围盒开 `scissor`，只对液滴区域着色，不再全屏重画壁纸。

这也是这版“流畅”的主要来源：全屏 8 次纹理采样变成只算液滴包围盒；壁纸由浏览器原生缩放。

## 三趟 + 相场

```
① CAC（低分辨率，ping-pong）        → φ
② 跳洪（同分辨率，9 pass）          → 最近界面距离
③ 高度 + 法线（同分辨率）            → h / N / mask
④ 合成（全分辨率，按包围盒 scissor） → 透镜 / Fresnel / HDRI / 介质 → 屏幕
```

几何层固定 0.24 屏宽；输出层自适应 0.7–1.5 DPR；壁纸不受输出 DPR 影响。

## 参数

| 参数 | 作用 |
|---|---|
| 初始滴数 | 初始化 tanh 斑块的数量；之后由 CAC 自然合并/分裂 |
| 尺寸 | 物理接触半径（mm）；调大按重力摊成水洼 |
| 接触角 | 球冠在接触线的角度 |
| 流场 | 全局无散度速度场强度 |
| 钉扎 | 接触线静摩擦阈值；默认 0，纯平流 |
| 界面宽度 | CAC 的 ε（相场格） |
| 迁移率 | Allen-Cahn 迁移率 |
| 模糊 / 高光 / 底色 / 环境 / 旋转 / 玻璃厚度 / 速度 | 观感与材质 |

## 仍然是近似

- 2D 相场是**接触线覆盖**，不是 3D 相场；高度是重建的，不是被 CAC 演化的；
- 体积约束在 φ 上；跳洪重建的**高度体积**不是严格守恒，界面变尖时润湿面积会轻微收缩；
- CAC 的 λ 是全局比例约束，不是严格的 Lagrange multiplier；
- 流场是给定的外部场，不是从空气压力/屏幕倾斜解出来的；
- 环境是一张固定 HDR 图，不是实时房间；
- 没有建模亚像素弯月面；
- 这是实时渲染里的相场近似，不是完整 NS / thin-film 求解器。
