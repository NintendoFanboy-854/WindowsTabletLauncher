# Liquid Glass · 动态引力场演示

这次不再做完整的相场/CFD。目标从“物理正确”改成“**便宜、稳定、看起来像水**”：

- 液体用一小组动态团块（blob）表示，总质量固定；
- 团块数量、位置、半径、质量都会变，不是固定水滴；
- 每帧对当前团块分布做**加权 k-means**，取 k 个质量簇中心作为 top-k 引力点；
- 每个团块只被**最近的**引力点吸引；
- 低频无散速度场平流团块，并在局部应变大时把团块拉裂；
- 团块靠近会合并，质量在合并/分裂中守恒；
- 渲染时把所有团块加成一个 metaball 场，得到光滑液面、法线和折射。

这样既有“分布 → top-k 引力点 → 吸引 → 速度场打散 → 新分布”的闭环，又不会像纯 φ 场那样摊成薄膜或碎片。

## 团块 / 界面

初始 6–7 个随机团块，半径和位置随机，质量归一化到 1。之后：

```
每个团块:
  v = 低频无散流场 + 最近引力点的吸引
  x += v·dt
  与 nearby 团块短程排斥           // 不全部并成一个大团
  距离足够近 → 合并（质量/面积相加）
  局部速度梯度大 → 分裂（质量/面积平分）
总质量始终归一化为 1
```

- 团块不是固定水滴；数量上限 8，会在合并/分裂中变化；
- 短程排斥让液滴保持独立，避免引力把所有质量收成一个球；
- 分裂是“速度场打散”的便宜实现：局部应变超过阈值时沿拉伸方向分成两个；
- 合并/分裂都保持总质量。

## top-k 引力点

不是固定坐标，而是每帧从当前团块分布里算出来的 k 个质量簇中心：

```
对团块位置做加权 k-means（权重 = 团块质量）
取 k 个簇中心，权重 = 簇质量
每个团块只被最近的引力点吸引
```

引力核是高斯导数 `r/σ · exp(−r²/2σ²)`：r=0 时为零，r≈σ 时最强，然后衰减；不会在数学奇点无限塌缩。

- `k` 控制团块被组织成几个质量簇；
- 引力点随分布移动、合并、消失；
- 速度场持续把团块拉长、拉裂，再被最近的引力点收回去。

## 渲染

液面纹理在 0.18 屏高上生成。对每个像素把所有团块加成一个 metaball 场：

```
F = Σ exp(−|p−p_i|² / 2r_i²)
G = ∇F
h = H · smoothstep-like(F)             // 高度
mask = smoothstep(0.06, 0.24, F)       // 接触线
N = normalize(vec3(−dh/dF · G, 1))     // 解析法线
```

- 多个团块重叠时 F 相加，界面自然融合；
- 高度和法线来自同一个光滑场，没有距离场中轴折痕；
- 合成层继续用现有光学：三波长 Snell、精确 Fresnel、屏幕玻璃、HDR 环境、参与介质、sRGB LUT；
- 全屏透明玻璃层，mask 外 early-out；没有 scissor，所以不会出现矩形裁剪；
- 输出分辨率自适应 0.55–1.4 CSS DPR。

## 参数

| 参数 | 作用 |
|---|---|
| 液体量 | 初始团块尺寸/覆盖；重置后生效 |
| 搅动 | 低频速度场强度；局部应变会把团块拉裂 |
| 引力 | top-k 引力点的吸引强度 |
| 引力半径 | 高斯引力核尺度 |
| 引力点数 | k-means 的 k；即 top-k 引力点数量 |
| 水滴高度 | metaball 场到屏幕高度的缩放 |
| 模糊 / 高光 / 介质浓度 | 观感与材质 |
| 环境亮度 / 旋转 / 玻璃厚度 | 环境与屏幕玻璃 |
| 速度 | 整体时间倍率 |

## 仍然是近似

- 不是 NS / 相场求解；液体是动态团块 + metaball 界面；
- 合并/分裂是离散事件，不是真正的界面拓扑演化；
- top-k 引力点是 k-means 拟合，不是物理重力场；
- 团块只受最近引力点吸引，是一种简化；
- 高度由 metaball 场重建，不是 3D 液面；
- 环境是固定 HDR 图，不是实时房间；
- 测试图里的矩形/网格是折射后的背景，不是裁剪。
