# Liquid Glass · 独立演示

按 Apple Liquid Glass 的材质描述做的实时实现：半透明、折射和反射背景、可清透可磨砂、会像液滴一样流动和融合。

## 材质

不是玻璃球，是**玻璃板**：中间是平的，光学效果全在倒角上。

```
dd = clamp(-d / bevel, 0, 1)         // 0 在轮廓，1 在倒角内侧
h  = sqrt(1 - (1-dd)²)               // 四分之一圆剖面
N  = normalize(vec3(n2 · (1-dd)/h, 1))
```

于是法线在平面上是 `(0,0,1)`（正对视线），到倒角才逐渐横躺。这一条决定了后面所有现象：

| 现象 | 表现 |
|---|---|
| **透射** | 平面处原样透过背景，只带一点色调和环境色 |
| **折射** | 只在倒角发生，把背景压进窄边 |
| **色散** | 红蓝用不同折射率，倒角边缘出彩边 |
| **菲涅尔** | 平面 F ≈ 0.04（几乎全透），倒角 F → 1（像镜面） |
| **高光** | 倒角上一段弧，不是一团光斑 |
| **环境着色** | 把周围环境的平均色吸进材质（Apple 说的 "adapt to their environment"） |
| **磨砂** | `模糊` 滑块，0 = clear，往上 = frosted |
| **气泡间反射** | 屏幕空间反射上一帧，倒角能照出旁边的另一滴 |

这几项正好对上网页里描述的那几条：折射和反射背景、用光照和 shader 表现 clear / frosted、随环境变色。

## 液态

形状是**圆**，用 `smin` 平滑并集。位置在 CPU 上算，因为要加粒子间的相互作用：

- **表面张力**：靠近的两滴互相拉一点，所以它们不是"飘到一起"，而是"被吸到一起"
- **液丝**：间距落在 2.0R–2.7R 之间时，中间会先拉出一根细颈，再断掉（Rayleigh–Plateau）

形变来自一个流场：`v = (ψ_y, −ψ_x)`，`ψ` 是照片亮度。旋度天然无散度（`div v ≡ 0`），所以面积守恒。每帧半拉格朗日回溯，形变因此带惯性。

## 光源

光的方向随相位缓慢绕行，倒角上的亮边会跟着爬。这一行让材质"活"了，不花任何额外开销。

阴影是体积阴影：用比尔-朗伯算吸收，厚的部分偏绿，而不是简单乘个暗色。

## 三趟管线

```
① 流场输运（fixed 0.18 屏宽，ping-pong）  → 距离场 + 深度
② 几何（同一分辨率）                       → 法线
③ 合成（全分辨率，渲到 ping-pong 缓冲）    → 折射 / 反射 / 高光
   └ 再 blit 到屏幕
```

第三趟渲到离屏缓冲而不是直接上屏，是为了让**下一帧**的倒角能反射这一帧的画面（屏幕空间反射）。双缓冲避免"一边渲染一边采样同一张贴图"的反馈回路。

低分辨率只输出几何，颜色全程全分辨率算，所以放大倍数再大也不会有马赛克。

## 参数

面板默认收起（按 **H** 展开）。性能相关的项全是自动的。

| 参数 | 作用 |
|---|---|
| 玻璃数量 | 同时存在几块 |
| 融合 | 两块靠近时脖子有多粗；0 = 硬边相交 |
| 折射 | 倒角把背景压弯的强度 |
| 色散 | 红绿蓝折射率差 |
| 模糊 | 0 = clear，往上 = frosted |
| 尺寸 | 每一块的半径 |
| 流场强度 | 照片把形状冲变形的力度 |
| 回拉 | 形状被拉回解析场的快慢 |
| 掩码尺度 | 用多糊的一层照片做流场 |
| 高光 | 倒角高光强度 |
| 环境着色 | 吸收环境色的程度 |
| 投影 | 接触阴影 |
| 速度 | 整体漂移速度 |

## 自适应

用 `EXT_disjoint_timer_query_webgl2` 读真实 GPU 耗时，预算按 120fps（8.3ms）定，留一倍余量，然后钉在 60fps 输出。五档同时调输出倍率和几何层倍率，两次调整至少隔 1.5 秒。

HUD 里 `质量 3/5` 是当前档，`GPU x.x ms` 是实测耗时。

## 无缝循环

所有运动频率都是整数（3 / 4 / 5 / 6），相位走满 `2π` 回到起点，周期约 47 秒，循环点无跳变。
